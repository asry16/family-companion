AWS Cloud Engineering

How Team Friday Uses AWS at the Core

AWS services are the operational backbone of security, telemetry ingestion, and emergency notification.

KinlyTelemetryStream

Amazon DynamoDB

• Ingests continuous device heartbeats (battery, charging, ringer, broad zone).
• 30-Day TTL: Automatic zero-cost data expiration prevents table bloat.
• Immutable Ledger: KinlyEmergencyEvents records all SOS triggers with tamper-proof timestamps.

Single-table Design • Auto-Scaling
kinly-family-vault

Amazon S3

• Zero-Trust Storage: Medical records, insurance papers, IDs encrypted with AES-256 Server-Side Encryption.
• Presigned URLs: Generates expiring 24-hour GET URLs for secure direct-to-device streaming without proxy bottlenecks.

Zero Public Bucket Access • AES-256
KinlyEmergencyAlerts

SNS & EventBridge

• Amazon SNS: Sends transactional emergency SMS alerts with GPS links directly to phones, bypassing data deadzones.
• EventBridge: Emits domain events (KinlyEmergencySOS, KinlyDocumentUploaded) for asynchronous processing.

Carrier SMS • Async Event Routing
Kinly/FamilyOS

Bedrock & CloudWatch

• Bedrock / SageMaker: Extracts amounts, providers, and due dates from bills to auto-create calendar reminders.
• CloudWatch: Tracks custom operational metrics (EmergencySOSTriggered, ActivePings) and audit logs.

Claude 3 Haiku • Custom Metrics
